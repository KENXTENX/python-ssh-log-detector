# Python SSH Log Detector

**Cereus Learning — Portfolio Project 02**

A defensive Python detection-engineering project. The initial repository is intentionally minimal while the implementation is developed and reviewed in a pull request.

**Status:** implementation in progress; no live SSH monitoring is claimed.

The planned implementation uses synthetic OpenSSH log fixtures, a configurable failure threshold and sliding time window, JSON alerts, unit tests, and GitHub Actions. It will later provide a foundation for a larger SOC lab.
